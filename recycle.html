Recycle Waste & Public Reuse

How We Recycle Waste

Waste is collected from smart bins and segregated into:

  • Wet Waste → Compost
  • Dry Waste → Sorting Center
  • Plastic → Recycle Plant
  • Metal → Smelting Units
  • Glass → Reuse Processing

Each bin is scanned using BIN ID and sent to the correct recycling facility.
